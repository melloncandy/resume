# Mellon Candy Portfolio Website

A beautiful animated portfolio website featuring an interactive flower background with growing stems, blooming petals, and magical light particles.

## Features

- **Animated Flower Background**: Complex 3D flower animations with growing stems and blooming petals
- **Multi-Page Navigation**: Three pages showcasing resume, kitten gallery, and video content
- **Dark/Light Theme Toggle**: Seamless theme switching with persistent storage
- **Fully Transparent Glass Design**: Clean, window-like transparency for content boxes
- **Responsive Design**: Mobile-first approach optimized for all devices
- **Interactive Elements**: Hover effects and smooth transitions throughout

## Pages

1. **Resume Page**: Professional profile with experience, skills, and downloadable APK
2. **Kitten Gallery**: Cute kitten showcase with interactive cards
3. **Video Page**: Cinematic background with thoughtful quotes

## Deployment

This website is deployed using GitHub Pages and contains only static files for optimal performance.

## Technologies Used

- React 18 with TypeScript
- Tailwind CSS for styling
- Custom CSS animations for flower effects
- Vite for build optimization
